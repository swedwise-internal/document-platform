# Create SaaS Sales Material

Generate sales and marketing materials for Swedwise Communications SaaS.

## Task
Create sales material: **$ARGUMENTS** (e.g., "one-pager", "pitch-deck", "demo-script", "faq", "roi-calculator")

## Material Types

### one-pager
Single-page fact sheet for quick customer overview.

```markdown
# Swedwise Communications (SaaS)
**Modern dokumenthantering som tjänst**

## Vad är det?
[2-3 meningar som beskriver tjänsten]

## Fördelar
- **Ingen infrastruktur**: Vi hanterar drift, uppgraderingar, säkerhet
- **Snabbare värde**: Standardiserad onboarding istället för månaders projekt
- **Förutsägbara kostnader**: Månadsabonnemang utan överraskningar
- **Enterprise-säkerhet**: ISO 27001, svenskt datacenter

## Funktioner
| Funktion | Beskrivning |
|----------|-------------|
| Dokumentgenerering | ... |
| Notifieringar | ... |
| API-integration | ... |

## Prissättning
[Övergripande prismodell]

## Kontakt
[Kontaktinformation]
```

### pitch-deck
Presentation structure (10-12 slides):

1. **Titel**: Swedwise Communications SaaS
2. **Utmaning**: Kundens smärtpunkter
3. **Lösning**: Vår tjänst översikt
4. **Hur det fungerar**: Teknisk översikt
5. **Fördelar**: Nyckelfördelar för kunden
6. **Säkerhet**: ISO 27001, svenskt datacenter
7. **Kundcase**: Exempel/testimonials
8. **Prissättning**: Övergripande modell
9. **Onboarding**: Hur snabbt kan kunden komma igång
10. **Nästa steg**: CTA, kontakt

### demo-script
Strukturerat demo-manus med:
- Pre-demo checklista
- Tidsplan (20-30 min)
- Nyckelscenarier att visa
- Talarpunkter per sektion
- Vanliga frågor att förvänta
- Call-to-action

### faq
Vanliga frågor kategoriserade:
- Tekniska frågor
- Säkerhetsfrågor
- Kommersiella frågor
- Support och SLA
- Integration
- Migrering

### roi-calculator
ROI-beräkningsunderlag med:
- Nuvarande kostnader (infrastruktur, underhåll, personal)
- Volymparametrar (antal dokument, användare)
- Swedwise SaaS kostnader
- Besparingar och vinster
- Break-even analys

## Value Propositions

### För IT-chef
- Minskad driftkomplexitet
- Automatiska uppgraderingar
- Skalbarhet utan migration
- Säkerhet utan extra arbete

### För Verksamhetsansvarig
- Snabbare time-to-market
- Förbättrad kundkommunikation
- Compliance-stöd
- Processförbättring

### För Inköp/CFO
- Förutsägbara kostnader (OpEx vs CapEx)
- Ingen investering i infrastruktur
- Transparent prissättning
- Flexibla avtal

## Target Audiences

- Offentlig sektor (kommuner, regioner, myndigheter)
- Finansiella tjänster (banker, försäkring)
- Utilities (energi, vatten, telekom)
- Stora företag med hög kommunikationsvolym

## Writing Guidelines

- Skriv på svenska om inget annat anges
- Använd kundnytta före funktioner
- Konkreta exempel och siffror
- Tydliga call-to-actions
- Anpassa till Swedwise varumärkesröst
