## 1. Purpose

This procedure defines how documented information required by the Integrated Management System (IMS) is created, approved, distributed, updated, and controlled to ensure:
- Documents are available when and where needed
- Documents are adequately protected
- Changes are controlled and traceable
- Obsolete documents are prevented from unintended use

## 2. Scope

This procedure applies to all documented information within the IMS, including:
- Policies and procedures
- Guidelines and work instructions
- Forms and templates
- Records and evidence
- External documents of regulatory or contractual importance

## 3. Definitions

| Term | Definition |
|------|------------|
| Document | Information and its supporting medium |
| Documented Information | Information required to be controlled and maintained |
| Record | Document stating results achieved or providing evidence |
| Controlled Document | Document subject to formal change control |

## 4. Responsibilities

| Role | Responsibility |
|------|---------------|
| IMS Owner | Overall document control system, master document register |
| Document Owner | Creating, updating, and reviewing assigned documents |
| Approver | Reviewing and approving documents before release |
| All Staff | Using current versions, following procedures |

## 5. Procedure

### 5.1 Document Creation

1. Identify the need for a new document
2. Determine document type and appropriate template
3. Assign document ID following naming convention:
   - `SW-[SYSTEM]-[TYPE]-[NUMBER]-v[VERSION]`
   - SYSTEM: IMS, QMS, EMS, ISMS
   - TYPE: POL (Policy), PRO (Procedure), GUI (Guideline), FRM (Form)
4. Draft content using the appropriate template
5. Include all required metadata (owner, date, version)
6. Submit for review and approval

### 5.2 Document Review and Approval

1. **Author** submits document for review
2. **Reviewer(s)** assess content for:
   - Accuracy and completeness
   - Clarity and usability
   - Compliance with standards
   - Consistency with other documents
3. **Approver** reviews and either:
   - Approves for release (sign-off in document control table)
   - Returns for revision with comments
4. Record approval in Document Register

**Approval Authority**:
| Document Type | Approver |
|---------------|----------|
| Policies | Management Team |
| Procedures | IMS Owner + Relevant Department Head |
| Guidelines | Document Owner + IMS Owner |
| Forms | Document Owner |

### 5.3 Document Distribution

1. Approved documents are published to [Document Repository Location]
2. Notification sent to relevant personnel for new/updated documents
3. Training provided if document requires significant behavior change
4. Hard copies are discouraged; if used, mark as "Uncontrolled Copy"

### 5.4 Document Control

1. Master documents stored in [Repository]
2. Document Register maintained by IMS Owner
3. Access permissions set according to information classification
4. Regular backup of document repository

### 5.5 Document Review and Update

1. Documents reviewed at least annually or as specified
2. Review triggered also by:
   - Changes in legislation or standards
   - Organizational changes
   - Audit findings or non-conformities
   - User feedback
3. Changes follow same approval process as new documents
4. Version number incremented:
   - Minor changes: 1.0 → 1.1
   - Major changes: 1.x → 2.0

### 5.6 Obsolete Document Control

1. When a document is superseded or withdrawn:
   - Remove from distribution
   - Mark as "Obsolete" if retained for reference
   - Update Document Register
   - Archive according to retention requirements
2. Obsolete documents retained for legal/historical reasons stored in [Archive Location]

### 5.7 External Documents

1. Identify external documents required for IMS (laws, standards, customer requirements)
2. Record in External Document Register
3. Monitor for updates through:
   - Subscription to regulatory updates
   - Vendor notifications
   - Industry association updates
4. Update internal documents when external requirements change

## 6. Inputs and Outputs

**Inputs:**

**Outputs:**
