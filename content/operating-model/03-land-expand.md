# 3. Land → Use → Expand

## Livscykel
```
CRM Deal → Commercial Package → Contract Lines → Delivery Plan → Work Packages/Deliverables
→ Time/Costs → Invoice/Revenue → Customer Health → Growth Signals → Expand Deal
```

## Mapping (bild → modell)
| Fas | Modellen |
|---|---|
| Prospect/Awareness | CRM deal + work items |
| Education/Selection | package + stage history + deal desk inputs |
| Commit | contract + contract_event(start) |
| Onboarding | delivery_plan + work_packages + deliverables |
| Use | tickets + SLA + environments + entitlements |
| Renew | contract_event(renewal) + health |
| Expand | growth_signal → new deal/contract_line under same Customer Program |

## Grundregel
- Varje “landad” kund har ett **CustomerProgram initiative**.
- Nya affärer (expand) ska normalt länkas till samma initiative.
