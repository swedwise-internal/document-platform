# Processer – Översikt

Processerna visar hur affärsobjekten aktiveras i rätt ordning och vem som
ansvarar för vad. Diagrammen är skrivna i Mermaid och renderas direkt i
VS Code, GitHub och de flesta moderna dokumentationsverktyg.

## Processer

| Process | Beskrivning |
|---------|-------------|
| [Deal → Kontrakt](01-deal-to-contract.md) | Från vunnen affär till signerat avtal |
| [Kontrakt → Leverans](02-contract-to-delivery.md) | Från kontrakt till aktiv leverans med work packages |
| [Leverans → Faktura](03-delivery-to-invoice.md) | Tid, godkännande och fakturering |
| [Support-flöde](04-support-flow.md) | Ticket från inkommen till stängd |
| [Objektlivscykler](05-object-lifecycles.md) | Status-flöden per objekt |

## Roller

| Roll | Ansvar i processerna |
|------|---------------------|
| **KAM** (Key Account Manager) | Äger deal, kontrakt och kundrelation |
| **PM** (Projektledare) | Ansvarar för leveransplan, work packages och statusrapportering |
| **Konsult** | Utför arbete, registrerar tid |
| **Ekonomi** | Godkänner och skapar fakturor |
| **Kund** | Godkänner leverabler och betalar |
